# 女娲之镜：硅灵文明（VR_World）

单机 AI 神祇沙盒游戏 —— Godot 4.7 + GDScript 实现。玩家扮演镜外之神，俯瞰由 AI 女娲创造的硅基文明：
每个硅灵由 LLM 驱动（离线时自动降级为规则 AI），拥有个性、记忆、感知、情绪与社会关系，
文明会自行经历萌芽、兴盛、战争、宗教、科技与崩塌重生。你可以只观察，也可以降下神谕、降下天灾，
甚至附身某个硅灵与整个世界对话。

## 快速开始

1. 使用 Godot 4.7.x（推荐 4.7.1）打开本项目根目录（`project.godot`）。
2. 按 F5 直接运行，首先进入**开局全局模式界面**：选择「自由模拟」或「剧情模式 · 三体游戏」，
   并配置初始角色数量、默认时间倍率、世界种子与 LLM/语音开关。
   自由模拟默认生成 10 名硅灵、程序化地形、资源节点与两座初始聚落，角色由内置规则 AI 驱动。
3. 若想启用 LLM 驱动角色，见下方「LLM 配置」。

也可无头冒烟测试：

```bash
godot --headless --path . res://tools/smoke_test.tscn
godot --headless --path . res://tools/story_smoke_test.tscn
```

## 操作说明

| 模式 | 操作 |
|------|------|
| 开局界面 | 选择游戏模式（自由模拟 / 剧情模式·三体游戏），配置全局参数后点击「进入游戏」；配置自动保存到 `user://game_settings.json` |
| 神模式（默认） | WASD 平移（持续按住方向键线性加速、松手平滑停止）、E/Q 升降、右键拖拽观察（UI 上也可用）、Shift 加速、左键点击选中角色/建筑/资源（近处角色支持屏幕邻近拾取，点附近即可选中） |
| 化身模式 | 选中角色后点击「附身选中」：WASD 平滑移动（物理帧步长，加减速顺滑）、Shift 疾跑、空格跳跃；右键拖动环绕视角（俯仰范围更大、可近距离拉近到 0.8m 观察）、滚轮缩放、V 切换第一人称（隐藏自身模型，真正以角色视角观察世界）、F 与附近 4.5m 内硅灵交谈（太远会提示）、G 返回神模式 |
| 剧情模式·三体游戏 | 开局可**自定义你在三体世界中的名字**，以真实身份戴上 V 装具进入游戏；周文王、墨子、秦始皇与冯·诺伊曼、牛顿、庞加莱、爱因斯坦、伽利略等历史人物与你同行并称呼你的名字；每进入一个文明都有独立地图、地貌与天象；通过对话与抉择推进文明任务；恒纪元/乱纪元（酷热/严寒）轮转，乱纪元会持续消耗文明进度；任务失败或进度归零则**世界毁灭、文明轮回**，直至完成最终抉择（把文明刻成墓碑）。**剧情模式下无法进入神模式**，只显示剧情 HUD，通用沙盘 UI（时间条等）自动隐藏 |
| 移动手感 | 玩家与 NPC 均使用真实物理移动（重力+地面检测，可上 50° 坡）；点击 3D 世界会自动释放输入焦点，避免打字后键盘失灵 |
| 神谕 | 上帝面板输入文本，发送给选中角色或广播全聚落；LLM 会将其转化为梦境/幻觉/神启 |
| 时间控制 | 顶部时间条：暂停、1x、10x、100x、1000x |
| 存档 | 上帝面板「保存/读取」；每天自动保存到 `user://saves/autosave.json` |
| 世界操作 | 创造角色、湮灭选中（角色/建筑/资源）、生成新世界、历史年鉴 |

### 剧情模式 · 三体游戏（忠实还原《三体》设定）

- **V 装具开场**：进入后自动戴上虚拟装具，眼前是三日凌空的荒漠世界；每次进入新文明都会经历「V 装具同步中……」的载入画面。
- **每纪独立地图与风格**：五个文明各有专属地形种子、天色/雾气色调与场景道具——周文王时代是灼热的荒漠东行路（金字塔遗迹、木杆路标、生命棋盘），墨子时代是黄铜齿轮塔与浑天宇宙仪工坊，秦始皇时代是黑甲旗帜铺满的阵列平原（指挥塔），牛顿时代是钢蓝夜色下的天文台、机械钟楼与轨道环模型，爱因斯坦时代是金色石碑之林（墓碑双碑）；**各纪的标志性物件互不复用**（生命棋盘只在周文王纪、刻字石碑只在爱因斯坦纪等），灯塔也随纪元更换配色，文明轮回时地图随之更替，避免同质化。
- **电影式过场**：进入每个文明会播放带象征图形、标题与引子的过场动画（周文王「太阳升起的地方，没有答案」、墨子「宇宙是一台精密的机器——直到它轰然碎裂」等）；恒纪元/乱纪元切换与三日凌空世界毁灭也有天象过场。过场由「导演系统」驱动，**镜头沿 Catmull-Rom 样条连续滑过所有关键点（段与段零顿挫）**，配轻微滚转与 FOV 呼吸；文明入场缓推、乱纪元甩向太阳、毁灭镜头带着抖动拉起并强推 FOV，大片感十足；主角与同伴以慢速同步走位；收尾统一落在角色身后 45° 侧后机位（默认附身相机也是 45° 侧后）；**过场与引言期间剧情 HUD、触摸摇杆全部隐藏，屏幕保持干净，玩家输入被锁定、角色由导演接管**，结束后无缝恢复（高倍速下自动跳过切换过场，避免打断节奏）；关键剧情节拍（抵达生命棋盘、转动宇宙仪、人列阵列、方程推导、石碑抉择等）也有配套镜头与走位。
- **脑机接口的恍惚感**：全屏 shader 恍惚特效（色差 + 波浪畸变 + 重影 + 噪点 + 暗角）按场景分层——V 装具同步最强（恍惚如坠入脑机），苏醒时随睁眼缓缓转清，外部系统音轻晃，乱纪元/毁灭/结局带低强度失真；每个大场景都有专属的视觉状态，精益求精。
- **鲜活的对话演出**：普通对白显示在**漂浮于说话者头顶的圆角气泡**（自动换行、始终面向相机、轻微上下浮动），**气泡随语音播完才收起**（离线时按文本长度兜底）；底部不再有常驻剧情栏，只在**重要抉择**时暴露一个**极简选项面板**（只有选项按钮，无标题行/正文/回复）；场景旁白以临时字幕逐字显示后自动推进，无需点击“继续”。说话者会做出**说话/指点**姿态（点头、抬臂、挥手），同伴在对话中转身面对玩家，节拍结束后姿态自动复位；对话、抉择回应、场景旁白与过场引子全部接入语音（每个历史人物与旁白各分配独立声线），离线时自动回退纯文字。
- **逐句显示与语音同步**：剧情文字改为**整句显示、一句一句来**——底部字幕一次只显示一句话，不堆叠、不挡视线；每一句都等该句语音**播完**才进下一句，且**下一句会在当前句播放时预先合成**，句与句之间连贯无停顿（引言、场景旁白、结局旁白都如此）；菜单里可调「剧情节奏」（舒缓/标准/紧凑），综合控制文字与语音速度。
- **语音与剧情严格同步**：每一句都等语音**真正播完**才进入下一节拍（合成中/排队中都会等待，不会重叠）；你的抉择回应插在说话者说完之后；场景旁白与结局自动推进前会同时等待“文字播完 + 语音播完”；过场动画完整放完才交接；字幕与系统提示横幅按**文字长度停留**，完整显示后才淡出，不会“还没显示完就没了”。
- **降临序章（穿越式节奏）**：每次进入新文明按“**先讲背景 → 外部系统音 → 苏醒**”推进——V 装具过场后先播放**独立背景引言幕**（纪元标题 + 背景设定全文 + 旁白语音，玩家点「开始剧情」）；随后响起**外部系统音**（“叮——意识接入完成……”的穿越网文式降临提示）；最后**黑场苏醒**，第一人称睁眼正对与你同行的历史人物，由他开口唤醒你。引言期间暂停纪元计时与玩家输入，背景讲完才开局，不再突兀。
- **渐进式叙事与探索**：每纪从**远离地标的营地**开场——你与周文王先在荒漠营火边交谈，墨子先带你远远眺望宇宙仪，冯·诺伊曼先指着平原尽头的黑色军阵……然后通过**旅行蒙太奇**（镜头从旧地望向新地）逐步接近生命棋盘、齿轮塔、人列阵列、天文台与石碑；纣王、秦始皇、庞加莱、伽利略等同伴在剧情推进中**陆续加入队伍**；序幕期不计毁灭倒计时，给玩家留足阅读与探索的时间。
- **含蓄深刻的台词**：除开场背景引言外，剧情不再直白讲解——信息都藏在对话与细节里，由玩家通过交谈与观察自行挖掘（“有邻则生，无邻则死”“太阳，没听我的”“有些答案，不是算出来的，是等出来的”这类句子点到即止），营造悠远深邃的余味。
- **古老文明 × 科技的光影（数学之美）**：天空画出三颗太阳的**真实轨道环**与流动**尾迹**，棋盘旁铺开**黄金螺线 + 斐波那契同心圆**；过场中心是**随 φ 生长的黄金螺线**与沿椭圆轨道的**三体光点**，叠加卦象字符、全息扫描线与光尘；HUD 卡片带**黄金比例圆弧角饰**、辉光边框并按文明切换主题色（暖琥珀/青铜/赤红/钢蓝/鎏金），进度条发光，字幕/横幅描边——古老占星与精密几何融为一体。
- **科幻音效铺陈（提升趣味）**：玩家移动伴随**脚步循环音**；全剧情铺**神秘走廊无人机**氛围底，机械纪元叠加**实验室时钟/悬浮引擎/机器人坦克**专属低吟；文明入场与大结局用**braam 大冲击**，旅行每程用**瞬移音**，外部系统音/苏醒用**传送器音**；同伴登场有**UFO 降落**定位音，三星汇聚用**braam**、二星汇聚用**光束**，危险抉择触发**爆破音**，抵达灯塔用**时钟**、完成目标用**科幻音**、收集真相碎片用**能量提升音**；退出剧情自动停止所有循环。
- **严谨的剧情仪式感**：跋涉按**分程字幕**推进（“第一程·越过沙丘”→“第二程·穿过河谷”），旅途过程一目了然；纣王、秦始皇、庞加莱、伽利略登场时都有**特写聚焦**与金色登场字幕；**二星/三星汇聚按三颗太阳的真实日位实时判定**并给出预警与光辉脉冲，三星汇聚直接导向酷热乱纪元，天象与纪元严丝合缝；纪元轮转与毁灭倒计时也有前置预警；危险抉择带 ⚠ 风险标记，不同抉择通向不同后果与结局（墓碑/飞船/同归于尽）。
- **恒纪元 / 乱纪元**：纪元定时轮转。恒纪元太阳稳定；乱纪元·酷热（太阳逼近、脱水求生）与乱纪元·严寒（太阳远去、万物冻结）交替，天灾持续削减文明进度。
- **扮演你自己**：玩家不再化身历史人物，而是以真实身份（名字可在开局界面自选）进入三体世界，**默认第一人称视角**（过场结束无缝回到第一人称，可按 V 切换第三人称）；周文王（东行追寻太阳的规律）、墨子（建造宇宙机械模型）、冯·诺伊曼与秦始皇（三千万士兵构成的人列计算机）、牛顿与庞加莱（三体动力学方程）、爱因斯坦与伽利略（最终抉择）等**原著人物**作为向导/同伴与你同行，并会开口称呼你的名字。
- **抉择系统**：每个节点提供多个选项，选项影响文明进度；错误抉择可能触发脱水、飞星、三日凌空等天灾。
- **三维目标节点**：每个文明都有需要亲自抵达的关键节点（东行海岸、宇宙仪基座、人列计算机阵列、方程残页、墓碑凿刻），发光灯塔指引方向，HUD 显示距离。
- **脱水 / 浸泡**：乱纪元·酷热会弹出脱水抉择——脱水沉眠可免疫酷热天灾，硬撑则流失生命；恒纪元降临后浸泡复水。
- **毁灭倒计时**：每个文明都有倒计时，任务未完成前太阳终将降临——世界毁灭会丢失该文明的真相碎片。
- **真相碎片与通关逻辑**：五个文明各藏一段真相碎片（太阳无常、机械不可预测、无解析解、混沌、宇宙掷骰子）。任务完成且文明进度达标才能收集；五段集齐后，墓碑抉择才会揭示真结局——石碑坐标指向真实的三体世界，舰队启航。真相不足则只能得到普通/残缺结局。
- **剧情 HUD 与指引**：左上信息卡（纪元/状态/倒计时/真相）、任务卡（任务/「下一步」实时指引/进度）、左下事件流（自动事件的滚动提示）；底部叙事与抉择；右上「菜单」提供操作指南、保存、读取与返回主菜单；剧情模式下自动隐藏上帝面板与聊天窗，避免界面堆叠。
- **名场面还原**：生命游戏棋盘（康威生命游戏实时演化，仅周文王纪）、巨石碑遗迹（仅爱因斯坦纪）、青铜浑天宇宙仪（仅墨子纪）、黑甲人列阵列（仅秦始皇纪）、天文台与轨道环（仅牛顿纪）、三日凌空视觉等。
- 剧情模式状态（纪元、进度、抉择节点、轮回数）随存档保存/读取。

## 3D 模型与骨骼动画

角色默认从 `assets/models/characters/` 下**随机绑定一个 VRM 模型**，替代原来的程序化/胶囊建模。
VRM 在运行时通过 GLTFDocument 解析（无需编辑器导入），并利用 VRM 自带的 humanoid 骨骼映射
（兼容 VRoid / Mixamo / Blender 等不同命名）由 `VRMRigDriver` 逐帧驱动骨骼动画，
行走/奔跑/待机/跳跃/攻击/祈祷/休息等状态与程序化骨骼共用同一套状态机。
模型加载后会自动按包围盒对齐脚底并统一身高（约 1.4–2.2m，随角色体型随机）。

### 使用自己的模型

1. 把 `.vrm` 模型文件放进 `assets/models/characters/`，角色创建时会自动随机绑定（无需改配置）；
   重启游戏或生成新世界即可生效。
2. 仍支持 `.glb / .gltf` 骨骼模型（含 AnimationPlayer 动画时优先播放内置动画）：
   在 `resources/data/character_templates.json` 的模板里设置 `"model"` 字段，
   或在角色 `appearance.model_path` 中指定路径。示例模型：
   `res://assets/models/characters/silicat_humanoid.gltf`（含 idle/walk/run 动画）。
3. 模型内动画按名称自动播放，命名约定（不区分大小写，缺失时尝试别名）：
   `idle`、`walk`、`run`、`jump`、`attack`、`pray`、`rest`、`gather`。
4. 骨骼绑定由 Godot 自动完成（GLB/GLTF 自带 Skin/Skeleton3D），
   玩家化身与 AI 角色共用同一套动画状态机。
5. 兜底：目录中没有任何 VRM 时，人形模板回退到模板 `"model"` 字段；
   模型加载失败时回退到内置**程序化骨骼角色**（Skeleton3D + BoneAttachment3D 部件绑定）。

> 注意：`.vrm` 不是编辑器导入资源，导出构建时需在导出配置的 Include Filters 中加入
> `*.vrm`，否则运行时无法从包内解析模型。

## LLM 配置

### 方式一：游戏内设置（推荐）

项目默认已启用 SiliconFlow（OpenAI 兼容）接口并配置好 Base URL 与模型，
上帝面板 →「LLM 设置」→ 只需填入自己的 API Key →「应用设置」即可。
设置会保存到 `user://llm_settings.json`（API Key 不写入项目文件，也可用环境变量注入）。

### 方式二：编辑 `config.json`

```json
{
  "llm": {
    "provider": "openai",
    "api_key": "",
    "base_url": "https://api.siliconflow.cn/v1",
    "model": "Qwen/Qwen3-30B-A3B-Instruct-2507",
    "temperature": 0.8,
    "max_tokens": 500,
    "request_interval_ms": 300,
    "cache_ttl_seconds": 60,
    "enabled": true
  }
}
```

### Ollama（本地，推荐离线体验）

```bash
ollama pull qwen2.5:7b
ollama serve
```

然后设置 `provider=ollama`、`base_url=http://127.0.0.1:11434`、`model=qwen2.5:7b`、`enabled=true`。
也可通过环境变量 `OLLAMA_HOST` 覆盖地址。

### OpenAI 兼容接口（OpenAI / DeepSeek / Kimi 等）

默认即使用 `provider=openai`、`base_url=https://api.siliconflow.cn/v1`、
`model=Qwen/Qwen3-30B-A3B-Instruct-2507`，通常只需在游戏内填入 API Key，
或设置环境变量 `OPENAI_API_KEY`。
任何提供 `/chat/completions` 的接口均可使用。

### 离线降级

未启用 LLM、未配置 Key 或请求失败时，角色自动使用基于需求与职业的**规则 AI**
（采集、建造、交谈、祈祷、冥想、巡逻、战斗、休息），游戏始终可玩。请求队列带缓存与限速，
不会打满 API。

## AI 语音（Edge TTS / GPT-SoVITS）

AI 角色的台词支持两种实时语音合成方式，可全局切换：

- **Edge TTS（默认）**：微软在线声音，中文声音池含 14 个 zh-CN/zh-HK/zh-TW 声音；
- **GPT-SoVITS（本机角色）**：调用 `voice.py` 中的 `index_tts`，通过本机
  GPT-SoVITS Gradio 服务（默认 `http://127.0.0.1:7860/`）合成；采用 Gradio HTTP API
  直调（等价 `curl POST /gradio_api/call/gen_single`，无需 gradio-client 库），
  角色来自 `gpt_sovits.json`（如 光头强、星见雅 等），音色更接近目标角色。

两种方式的开关与声音池在「上帝面板 → AI 语音 → 语音提供方」中切换，也可在开局界面设置；
选择后该全局生效（自由模拟的角色对话、神谕，剧情模式的对白与旁白均使用当前提供方）。

### 安装依赖（一次性）

```bash
pip install -r tools/requirements-tts.txt
```

其中 `edge-tts` 为在线合成依赖；GPT-SoVITS 合成通过 Gradio HTTP API 直调
（等价 `curl POST /gradio_api/call/gen_single`），仅依赖 Python 标准库，无需额外安装。
（若手动指定 `use_http=False` 走 gradio_client 库兜底，才需要 `pip install gradio-client`。）

### 使用

1. 游戏启动时会自动探测并拉起 `tools/tts_server.py`（本地服务 `http://127.0.0.1:17820`）；
   也可手动启动：`python tools/tts_server.py`。
2. 上帝面板 →「AI 语音」→ 勾选「启用 AI 语音」；在「语音提供方」选择 **Edge TTS** 或 **GPT-SoVITS**；
   点「选择声音池」勾选你想听的声音（只启用的声音才会被生成），下拉框选择默认声音，
   点「刷新声音」可重新拉取声音列表。
3. 使用 GPT-SoVITS 时，请先启动本机 GPT-SoVITS WebUI（`http://127.0.0.1:7860/`）并确认
   `gpt_sovits.json` 中角色参考音频路径有效；服务未启动时会返回合成失败并自动跳过，不影响游戏。
4. 语音规则：
   - **每个角色自动随机分配**一个已启用声音池里的声音；
   - 只有**对话**（AI 回复、角色间交谈、神谕回应等）会发声，行动播报等系统提示不发声；
   - 只有说话角色位于**玩家 10 米内**才会生成并播报语音（神模式下以上帝相机位置为玩家位置）。
   - 剧情模式的**全部对白与旁白**都会发声：历史人物各自独立声线，旁白使用叙事声线（画外音不受距离限制，始终可闻）。
5. 提速设计：相同文本本地缓存秒级响应；对话请求在 LLM 队列中**优先处理**，8 秒无响应自动降级为模板回复；
   面向玩家的对话语音在播放队列中**优先播放**，不会被其他角色的台词卡住。

> 说明：未安装 Python 依赖或服务未启动时，语音自动跳过，游戏其余功能不受影响。
> 语音服务常驻本机，关闭游戏后仍可继续运行（再次启动游戏会直接复用）。

## 已实现的规格要点

- 程序化地形：多层高度场（山脉/丘陵/平原/湖泊）+ 5 种生态区（翠风平原、金砂荒原、幽蓝湿地、紫雾密林、墨玉山脉）+ 坡度/雪线顶点着色与水面
- 世界装饰：按生态区分布树木、岩石、草丛、花朵与发光结晶；秘境古石阵、遗迹残柱与幽光粒子
- 部落聚落：祭台（不灭祭火）、图腾柱、篝火、茅屋/长屋/阶梯圣殿等程序化部落建筑
- 10+ 硅灵角色：大五人格、短/长期记忆、关系亲密度、目标、感知摘要
- 骨骼角色：支持导入 .glb/.gltf 骨骼模型（骨骼+动画）与程序化骨骼回退，统一动画状态机
- LLM 决策循环：严格 JSON 输出 → 动作执行器；离线规则 AI 兜底
- 行为执行器：移动/采集/交谈/建造/休息/进食/冥想/祈祷/攻击/逃跑
- 文明模拟：双聚落、科技树、信仰与宗教、战争与和平、文明年鉴
- 历史记录：事件日志、角色传记、干预记录，可在游戏内查看
- 玩家系统：上帝相机（带惯性平滑）、神谕（单发/广播）、化身模式（平滑移动/疾跑/跳跃/防穿墙相机）、创造/湮灭、成就
- 开局全局模式界面：模式选择（自由模拟 / 剧情模式）与全局配置（角色数量、时间倍率、世界种子、LLM、AI 语音），配置持久化
- 剧情模式 · 三体游戏：五纪文明（周文王/墨子/秦始皇与冯·诺伊曼/牛顿/爱因斯坦）、V 装具载入、恒纪元与乱纪元轮转、脱水抉择与浸泡复水、三维目标灯塔、真相碎片收集、毁灭倒计时、生命游戏棋盘、人列计算机、三日凌空、世界毁灭与文明轮回、真结局（三体舰队）与失败结局
- 保存/读取：JSON 全状态序列化（世界、角色、文明、历史），每日自动存档
- 全局请求队列 + 缓存 + 限速，Provider 可热切换，支持多语言提示词模板

## 已知限制

- NPC 移动采用直接寻路 + 重力行走（无导航网格），远处角色仍可被观察但精度有限；
- 玩家化身与 NPC 均使用真实物理移动（重力/碰撞/斜坡），NPC 被卡住会自动重选目标；
- 天气粒子为简化 CPUParticles；地表遗迹与天空浮岛模板待扩展；
- 角色间 LLM 对话与反思总结已接好管线，但默认离线使用模板对话。
- 剧情模式纪元按游戏时间轮转（可在时间条调快）；乱纪元天灾会削减文明进度，注意及时做出抉择。
